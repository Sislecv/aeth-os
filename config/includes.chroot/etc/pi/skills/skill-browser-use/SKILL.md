# Browser Use Skill

Provides tools for AI agent browser navigation, snapshotting, and interaction:
- `browser_open`: Launch browser and navigate to a URL.
- `browser_snapshot`: Capture accessibility snapshot with numbered `@eN` references.
- `browser_click`: Click interactive element `@eN`.
- `browser_fill`: Fill input fields with text.
- `browser_read_markdown`: Convert webpage content to readable Markdown.
- `browser_reveal`: Reveal browser window on User Workspace 1 for manual CAPTCHA/login.
