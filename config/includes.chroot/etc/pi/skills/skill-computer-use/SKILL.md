# Computer Use Skill

Provides tools for AI agent interaction with desktop graphical applications running in Workspace 2 (Ghost Workspace):
- `desktop_inspect_tree`: Inspect UI accessibility elements (role, label, coordinates) via AT-SPI2.
- `desktop_click_element`: Click at coordinates or on specific widgets.
- `desktop_type_text`: Type text or send keyboard hotkeys.
- `desktop_screenshot`: Capture non-disturbing screen image for visual analysis.
- `desktop_ghost_switch`: Manage Workspace 2 status and viewport.
