# OS Admin Skill

Provides system-level administration tools for AgenticOS:
- `sys_doctor`: Comprehensive hardware health (RAM, zRAM, battery, storage, GPU).
- `sys_wifi_status`: Scan and check WiFi status via NetworkManager.
- `sys_wifi_connect`: Connect to WiFi network.
- `sys_package_info`: Query Debian package information and dependencies.
- `sys_package_install`: Install packages non-interactively via apt.
- `sys_zen_mode`: Toggle Do Not Disturb and Zen focus mode.
